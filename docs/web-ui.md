# Web 页面使用说明

页面标题为“标准辊密封生成”。顶栏只保留标题和任务进度入口，布局、表格、输出区与弹窗使用相同的卡片风格，自动适配深浅色主题。

## 参数与导入

- 网页显示前 14 列参数，保留子头与母槽开关；子头宽、子头突出、母槽宽、母槽深不占用表格空间。
- CSV 中提供这四项尺寸时采用导入值，缺列或空白时使用模板默认值。
- 两侧斜边都关闭时，斜边 Y/Z 可留空；任一侧开启时仍需有效正数。
- “检查参数”通过后，居中显示“没有错误”并自动关闭；失败时显示具体原因，需手动关闭。

## 服务器计算版

- API Key 在连接弹窗输入，成功后在当前浏览器记忆；已有有效密钥自动连接，没有密钥或密钥失效时重新弹窗。顶栏不常驻显示密钥输入、连接状态或访问设置。
- 快速输出提供独立的 DXF、PDF 文件；项目输出勾选 DXF、单件 STEP、PDF、列表 CSV，下载仅包含勾选文件的 ZIP。网页不提供合并 STEP 与合并文件名设置。
- 隐藏线比例和视图间距直接使用服务器默认值。

## 浏览器计算版

建模、单件 STEP、SolidCraft 文件和可选 CSV 在浏览器中生成并打包 ZIP。页面不再提供合并 STEP；浏览器端 DXF/PDF 尚未接入，不会自动回退到服务器计算。

## 进度与手机操作

生成立即弹出任务窗口，显示具体任务说明、当前步骤计数、进度和结果操作；关闭不会取消生成，可从顶栏重新打开。空日志隐藏，有内容时默认收起。进度计入单件建模、出图、保存、后处理及结果准备，结果可下载后才到 100%；未按耗时模拟百分比。

宽屏表格按内容增高，上限扣除顶栏、工具栏等实际占用；手机常态约四行，矮屏进一步缩小，超出内部滚动。手机隐藏单位与粘贴提示整行，加宽操作列并收窄前六个参数列。页面禁用双击放大、保留双指缩放；输入框保持聚焦所需字号，数字以较紧凑的视觉尺寸显示。
